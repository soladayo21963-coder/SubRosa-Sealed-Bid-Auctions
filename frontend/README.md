# SubRosa Frontend

This frontend provides the buyer and seller experience for SubRosa sealed-bid auctions.

## Features
- Freighter wallet connection
- auction dashboard shell
- bid form and collateral input
- clean dark-mode experience for a modern DeFi aesthetic

## Local development

```bash
npm install
npm run dev
```

## Environment

Add the deployed contract address to a `.env.local` file:

```bash
NEXT_PUBLIC_SUBROSA_CONTRACT_ID=your_contract_id_here
```
